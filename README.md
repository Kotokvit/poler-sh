# 🔒 POLER-SH — Суверенная командная оболочка и терминальный шлюз (Terminal Gateway)

Автономный, сверхбыстрый (3.3 мс) интерпретатор команд и терминальный шлюз для ИИ-агентов и суверенных операционных систем.

---

## ⚡ Особенности

1. **Заменитель bash / sh:**
   * Прямой запуск процессов без медленных форков и промежуточных шеллов.
   * Совместимость с POSIX: `poler-sh -c "<cmd>"`.
2. **Машиночитаемый шлюз для ИИ-агентов:**
   * `poler-sh --exec "<команда>" --json` $\to$ единый защищённый конверт `{cmd, ok, exit_code, duration_ms, output}`.
3. **Нативный AST-калькулятор:**
   * `calc 2^64-1`, `calc sin(pi/4)`, `calc sqrt(1024)` — мгновенно, без вызова python/bc/awk.
4. **Физический конвертер единиц:**
   * `= 100 km/h to m/s`, `= 16 GiB to MB`, `= 5 mi to km`.
5. **Аппаратный аудит без внешних утилит:**
   * `hw` — мгновенный срез топологии CPU, кешей L1–L3, RAM и GPU.
   * `sysinfo` — карта среды исполнения.
6. **$O(1)$ память и нулевые внешние зависимости:**
   * Никаких тяжелых фреймворков. Бинарник весит ~1.5 МБ.

---

## 📦 Сборка и установка

```bash
cargo build --release
cp target/release/poler-sh ~/.local/bin/
```

## 🚀 Использование

### Интерактивный режим:
```bash
poler-sh
```

### Вызов из агента:
```bash
poler-sh --exec "calc 2^32" --json
```
